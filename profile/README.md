# lo.cafe™

We make apps for Mac and iPhone. **lo.cafe Ltda.** is the company behind **NotchNook**, with projects including **lo-rain** and **Winston**.

[Official website](https://locafe.app/) · [Company](https://locafe.app/company/) · [Our story](https://locafe.app/history/)

## Our apps

- **[NotchNook](https://getnotchnook.com/)** — music, calendar, notes, tasks and files, right in your Mac’s notch. [NotchNook by lo.cafe](https://locafe.app/notchnook/).
- **[lo-rain](https://locafe.app/lo-rain/)** — rain over your Mac desktop. See original recordings and project history.
- **[Winston](https://locafe.app/winston/)** — a native Reddit client for iOS, built with Swift and SwiftUI. [Source code and releases](https://github.com/lo-cafe-ltda/winston).

[NotchNook documentation and support](https://github.com/lo-cafe-ltda/notchnook)
